# Heart Disease Risk Estimation

Estimate the risk of heart disease from clinical measurements.

## Approach

- Exploratory analysis by age and clinical indicators
- Logistic Regression, KNN, SVM, Naive Bayes, Decision Tree, Gradient Boosting and Random Forest

## Results

Accuracy between about 0.75 and 0.85 in the saved notebook output.
